# **🚀 Curso Completo de SQL y PL/SQL en Oracle**

## 📌 Introducción

Este repositorio contiene un curso completo de SQL y PL/SQL en Oracle, diseñado para llevarte desde lo más básico hasta un nivel experto en bases de datos.

### 📚 Objetivos:

- Aprender la sintaxis y funcionalidades de SQL en Oracle.

- Dominar la programación en PL/SQL.

- Aplicar conceptos avanzados en entornos empresariales.

- Optimizar consultas y trabajar con estructuras de datos complejas.

Este curso sigue un enfoque estructurado con un roadmap detallado, dividiéndose en cinco niveles de dificultad.

## **🔹 Roadmap Completo de SQL en Oracle**

### 1️⃣ Nivel Básico – Fundamentos Esenciales:

- Conceptos fundamentales de SQL y bases de datos relacionales.

- Tipos de datos en Oracle: numéricos, texto, fechas y binarios.

- Lenguaje de Definición de Datos (DDL): CREATE TABLE, ALTER TABLE, DROP TABLE.

- Lenguaje de Manipulación de Datos (DML): INSERT, UPDATE, DELETE.

- Consultas básicas con SELECT, WHERE, ORDER BY.

### 2️⃣ Nivel Medio – Consultas Intermedias

- Subconsultas (SELECT dentro de SELECT).

- Operaciones entre conjuntos (UNION, INTERSECT, MINUS).

- Funciones de agregación (SUM, AVG, COUNT, GROUP BY, HAVING).

- Expresiones condicionales (CASE, DECODE).

- Manejo de fechas y funciones (SYSDATE, MONTHS_BETWEEN, ADD_MONTHS).

- Manejo de valores nulos (NVL, COALESCE).

### 3️⃣ Nivel Medio Avanzado – Consultas Complejas

- Joins Avanzados: INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN, CROSS JOIN.

- Common Table Expressions (CTEs) con WITH.

- Particionamiento de Datos (PARTITION BY).

- Funciones Analíticas (LEAD, LAG, RANK, DENSE_RANK).

- Optimización con EXPLAIN PLAN y Materialized Views.

### 4️⃣ Nivel Avanzado – Estrategias Empresariales

- Índices avanzados (Function-based, Partitioned).

- Consultas jerárquicas (CONNECT BY PRIOR).

- Tablas particionadas (Range, List, Hash).

- Seguridad en bases de datos: Roles, Grants y Privilegios.

### 5️⃣ Nivel Experto – Grandes Corporaciones

- Data Warehousing en Oracle.

- Automatización con DBMS_SCHEDULER.

- Optimización con AWR, ADDM.

- Seguridad avanzada con VPD, Data Guard.

- Consultas en bases distribuidas (DBLINK).<br><br>
<br>

# **🔹 Roadmap Completo de PL/SQL en Oracle**

### 1️⃣ Nivel Básico – Fundamentos

- Introducción a PL/SQL y diferencias con SQL.

- Creación de bloques anónimos.

- Variables y estructuras de control (IF, LOOP, CASE).

- Manejo de errores con EXCEPTION.

### 2️⃣ Nivel Medio – Procedimientos y Funciones

- Cursores implícitos y explícitos (OPEN, FETCH, CLOSE).

- Creación de Procedimientos (PROCEDURE) y Funciones (FUNCTION).

- Triggers (BEFORE, AFTER, INSTEAD OF).

### 3️⃣ Nivel Medio Avanzado – Modularización y Optimización

- Uso de Packages (PACKAGE y PACKAGE BODY).

- Cursores avanzados con parámetros y REF CURSOR.

- Procesamiento en lotes con BULK COLLECT y FORALL.

### 4️⃣ Nivel Avanzado – Escalabilidad y Seguridad

- Manejo de transacciones (COMMIT, ROLLBACK, SAVEPOINT).

- Bloqueos y concurrencia (SELECT FOR UPDATE).

- Automatización con DBMS_SCHEDULER.

### 5️⃣ Nivel Experto – Aplicación en Grandes Corporaciones

- Uso de DBMS_PROFILER para optimización de rendimiento.

- Seguridad con Virtual Private Database (VPD).

- Implementación de replicación y alta disponibilidad (Data Guard).
